# 🍔 EloLanches

Bem-vindo ao projeto **EloLanches**!

Este é um site simples para uma lanchonete, desenvolvido com HTML, CSS e JavaScript.

## 📋 Funcionalidades

- Página inicial da lanchonete
- Cardápio de produtos
- Área de contato
- Botão interativo de pedido
- Layout responsivo e fácil de personalizar

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

## 📁 Estrutura do Projeto

```text
EloLanches/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 Como Executar

1. Baixe ou clone este repositório:
   ```bash
   git clone https://github.com/seu-usuario/elolanches.git
   ```

2. Abra o arquivo `index.html` em seu navegador.

## 🌐 Publicação com GitHub Pages

1. Faça upload dos arquivos para um repositório público no GitHub.
2. Vá em **Settings > Pages**.
3. Selecione:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
4. Salve as alterações.

Seu site ficará disponível em:

```text
https://seu-usuario.github.io/elolanches/
```
